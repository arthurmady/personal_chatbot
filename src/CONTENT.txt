Étape 0 — Setup
Environnement Python, structure de projet, OmniRoute lancé en local, test d'un premier appel API.

Étape 1 — Ingestion multi-format
Parser PDF/Word/txt/md/web en texte brut normalisé, avec métadonnées (source, date, type).

Étape 2 — Chunking
Découper le texte en chunks pertinents (stratégie fixe vs sémantique), avec overlap.

Étape 3 — Embeddings + stockage Qdrant
Choisir un modèle d'embedding, créer la collection Qdrant, indexer les chunks avec leurs métadonnées.

Étape 4 — Retrieval
Requête → embedding → recherche vectorielle (top-k), éventuellement reranking.

Étape 5 — Génération contrainte (le cœur de ta demande)
Prompt system strict pour forcer le LLM à répondre uniquement à partir du contexte injecté, gestion du cas "je ne sais pas".

Étape 6 — Garde-fous / limites de réponse
Détection de hors-sujet, refus propre, citation des sources, anti-hallucination.

Étape 7 — Interface
CLI simple puis API (FastAPI) puis, si tu veux, une UI (Streamlit/Gradio).

Étape 8 — Évaluation
Mesurer la fidélité au contexte (faithfulness), la pertinence du retrieval, etc.

src/llm_client.py

C'est ta seule dépendance vers OmniRoute — comme il expose une API compatible OpenAI, le SDK openai officiel fonctionne directement en changeant juste base_url. Ça t'évite d'écrire du HTTP à la main, et si tu changes de gateway plus tard, un seul fichier à toucher.

python
from openai import OpenAI
from config import OMNIROUTE_BASE_URL, OMNIROUTE_MODEL

client = OpenAI(
    base_url=OMNIROUTE_BASE_URL,
    api_key="not-needed",  # OmniRoute ne vérifie pas de clé en local
)

def ask_llm(messages: list[dict], model: str = OMNIROUTE_MODEL) -> str:
    """
    messages: liste au format [{"role": "user", "content": "..."}]
    Retourne le texte de la réponse.
    """
    response = client.chat.completions.create(
        model=model,
        messages=messages,
    )
    return response.choices[0].message.content
